ℹ About StrumGroove

StrumGroove v2.1 is a self-contained strum trainer that runs entirely in your browser — no server, no account, no internet connection needed after first load (fonts are the only external resource).


Your data stays with you. No strumming patterns, custom beats, or queue settings are ever sent anywhere. Everything lives in this HTML file and in your exports.


All sound is synthesised using the Web Audio API — no audio files are downloaded.


Built with ❤️ using HTML, CSS and vanilla JavaScript.
