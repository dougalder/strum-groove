Key Features

  • No installation — works in any modern browser
  • Completely offline after first load
  • Runs on desktop, tablet, and mobile
  • Adjustable tempo (40–200 BPM)
  • Sound options (warm, bright, mellow, sharp)
  • Screen wake lock for iOS 16.4+
  • Queue patterns for practice sessions
  • Edit and customize any pattern
  • Light & dark themes with auto-save
  • No account, no tracking, no ads

Browser Support

Desktop: Chrome 86+, Safari 14+, Firefox 79+, Edge 86+

Mobile: Safari 14.4+ (iOS), Chrome 86+ (Android)

Features: Screen wake lock requires iOS 16.4+ Safari or Chrome 84+
